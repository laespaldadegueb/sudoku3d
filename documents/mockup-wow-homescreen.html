Notes de disseny per a cada proposta
Proposta A · Cube Splash
El cub com a protagonista absolut
L'animació de "bob" (flotació lleu) és la primera cosa que veu el jugador. Els números que floten com partícules reforcen el tema numèric. El fons de paper quadriculat crea sensació de joc analògic premium.
✓ Màxim impacte visual amb la paleta actual
✓ Fàcil d'implementar amb SVG + CSS
✓ Coherent amb el disseny "Zen Paper" existent
✗ Els jocs secundaris queden amagats
✗ Requereix pantalla prou alta (≥580px)
Proposta B · Game Gallery
Tots els jocs descoberts a primer cop d'ull
El menú "Més jocs" desapareix: ara tot és visible. Cada targeta és un joc diferent amb el seu color propi. L'usuari entén immediatament la riquesa de l'app. Scroll vertical natural.
✓ Descobriment màxim: 5 jocs visibles
✓ Colors de joc com a identitat visual
✓ Previsualitzacions de graella orientatives
✗ El 3D perd protagonisme
✗ Requereix scroll per veure el botó diari
Proposta C · Night Cosmos
Mode fosc immersiu estil "app de joc"
Trencament total amb el disseny actual. Els números de fons creen ambient sense soroll visual. El cub lluu com un objecte màgic. Pot coexistir amb el mode fosc del sistema operatiu.
✓ Sensació de "joc" molt forta
✓ Diferenciador total en el mercat
✓ El glow de terracota és molt efectiu
✗ Trencament amb la paleta "Zen Paper"
✗ Pot ser menys llegible en entorns lluminosos
